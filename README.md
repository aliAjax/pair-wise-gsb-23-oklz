# hxwl-09 擦拭采样与房间放行台

洁净室换产开工前，凭表面微生物擦拭结果放行房间的看板。

## 业务规则

- 按房间点位登记擦拭结果：换产消毒批次、消毒剂批次、培养基批次、菌落数（CFU/碟）、检验员。
- **同一点位同一消毒批次只留一条**，重复登记更新原记录，不新增。
- 出现以下任一情况，房间停在「待处理」，禁止开工：
  - 消毒剂或培养基批次已过期；
  - 点位漏采（复擦必须复测全部点位）；
  - 菌落数超过房间洁净等级限值。
- 复擦须**换人**（同一点位不得由上一轮同一检验员复测），并覆盖全部点位。
- 全部点位合格后判定放行，该轮结果**冻结**，记录不可再改。
- **改判不覆盖**：只新增带原因的版本（V1、V2…），历史版本完整保留。

## 分层结构

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 资料 | `src/types.ts`、`src/data/seed.ts` | 领域模型、房间/点位/批次/检验员台账、演示数据 |
| 判定 | `src/domain/rules.ts` | 过期、漏采、超限、换人、放行状态等纯函数规则 |
| 保存 | `src/storage/repository.ts` | localStorage 持久化与带校验的状态变更 |
| 页面 | `src/App.tsx`、`src/components/*` | 看板、房间卡片、轮次详情、登记表单、批次台账 |

## 技术栈

React + Vite + TypeScript + CSS（无额外运行时依赖）

## 本地运行

```bash
npm install
npm run dev
```
